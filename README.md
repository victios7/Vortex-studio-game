# Generador de Biomas Procedural

Este proyecto consiste en un generador de mundos procedural para Roblox Studio.

Cada vez que un jugador se une se genera un mundo de 100x100 completamente distinto. El sistema elige aleatoriamente un bioma entre Normal, Taiga, Desert, Rocky y Badlands y genera el terreno usando ruido Perlin y FBM.

El terreno incluye vegetacion y estructuras propias de cada bioma como casas, cabañas, piramides, torres y minas. La tecla E permite borrar el mundo actual de forma gradual y generar uno nuevo.

El proyecto esta optimizado para correr en el lado del cliente, funciona fluido incluso en modo ultra sombras, con 60 FPS maximo en el motor de Studio y hasta 240 FPS en cliente.
